# 2D Texture Rendering

An Object-Oriented C++ application demonstrating the core principles of the modern graphics pipeline. This project initializes an OpenGL 4.6 context to render a 2D textured object, utilizing custom Vertex Array Objects (VAOs) and Vertex Buffer Objects (VBOs) to bind coordinate and color data to a dynamically rendered crate sprite.
